To configure model-based report access:

1. Go to **Settings > Users & Companies > Groups** and select the Group you want to configure.
2. Under the **Report Access** tab, click **Add a line**.
3. Select the target **Model** and choose the permitted reports in the **Allowed Reports** field.

Note: By default, report filtering is inactive if no records exist for a model. This maintains Odoo's native access control behavior until a restriction is explicitly defined.
