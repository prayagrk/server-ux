Once report access is configured for user groups:

1. Assign the appropriate groups to the user.
2. The user navigates to the target model view (e.g., Partners).
3. Under the **Print** action menu, the user will only see the specific reports that have been explicitly allowed by their assigned groups. All other reports are hidden.

**Note on New Reports:** Under the "Deny by Default" model, if a model has restrictions defined, installing new modules that add reports will hide those reports from all users (except superusers) until they are explicitly added to the allowed reports of the appropriate user groups.
