This module extends Odoo's role-based security system to provide granular, role-based visibility control over Server and Window Actions:

1. It introduces the ability to configure "Allowed Server Actions" and "Allowed Window Actions" on Access Rights.
2. It strictly enforces a "Deny by Default" policy, ensuring that users can only view and execute actions explicitly permitted by their assigned Roles.
3. Automatically populates existing action access during installation to prevent disruption.
