To configure role-based action access:

1. Go to **Settings > Users & Companies > Roles** and select the Role you want to configure.
2. Under this Role, identify the implied Groups that grant access to the relevant models.
3. Edit the Group's **Access Rights** tab.
4. For the model access rules, specify the permitted actions in the **Allowed Server Actions** and **Allowed Window Actions** fields.

All permitted actions from the groups implied by a user's active Roles will be automatically aggregated and dynamically enforced.
