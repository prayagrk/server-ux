Base Action Manager

This module extends Odoo’s role-based security system to provide granular, role-based visibility control over Server and Window Actions:

  1. It introduces the ability to configure “Allowed Server Actions” and “Allowed Window Actions” on Access Rights.
  2. It strictly enforces a “Deny by Default” policy, ensuring that users can only view and execute actions explicitly permitted by their assigned Roles.
  3. Automatically populates existing action access during installation to prevent disruption.

Configuration

To configure role-based action access:

  1. Go to Settings > Users & Companies > Roles and select the Role you want to configure.
  2. Under this Role, identify the implied Groups that grant access to the relevant models.
  3. Edit the Group’s Access Rights tab.
  4. For the model access rules, specify the permitted actions in the Allowed Server Actions and Allowed Window Actions fields.

All permitted actions from the groups implied by a user’s active Roles will be automatically aggregated and dynamically enforced.

Usage

Once action access is configured for a Role:

  1. Assign the Role to a user (and ensure the Role is active).
  2. The user navigates to the target model (e.g., Partners).
  3. Under the Action gear icon menu, the user will only see the specific server and window actions that have been explicitly allowed by their active Roles. All other actions are hidden.

Note on New Actions: Under the “Deny by Default” model, installing new modules that add contextual actions will hide those actions from all users (except superusers) until they are explicitly added to the allowed actions of the appropriate Role’s implied groups.
